To run the MIPS program to implement the IsFibonacciOdd function for a given n, we did the following steps: First, we launched MARS and went to File, Open, and selected IsFibonacciOdd.asm. We set the input n by editing n: .word 10 in the .data section, and hit save. Then we assembled and ran the program. The result will be displayed in the Run I/O panel and stored in memory at the label result; if the number shown is 1, the nth Fibonacci number is odd, and if it shows 0, the nth Fibonacci number is even.
